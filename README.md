# Week 2 Express API
A simple REST API built with Express.js.

## Endpoints

- `GET /skills` — returns all skills
- `GET /skills/:id` — returns a single skill by index
- `POST /skills` — adds a new skill

## Setup

1. Install dependencies: `npm install`
2. Create a `.env` file: `PORT=3001`
3. Run: `node index.js`

## STACK
- Node.js
- Express.js
- dotenv
- cors
